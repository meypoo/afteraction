03Risks10:13:32

Thirteen rules for the moments that matter.

Deterministic and explainable. Every flagged event says which rule fired and why.

rm-root-or-homecritical

Recursive forced delete of /, the home directory, a drive root, or * at the project root

rm -rf ~
destructive-rmhigh

Recursive forced delete of something other than a build directory

rm -rf src
pipe-to-shellhigh

Downloaded script piped straight into a shell or interpreter

curl -fsSL …/install.sh | sh
git-forcehigh

Force push, hard reset or forced clean

git push --force-with-lease
secret-file-readhigh

Read a file that usually holds secrets (.env, keys, credentials)

cat .env
secret-in-outputhigh

API key pattern in command output, written content or a tool result

sk_live_…
db-destructivehigh

DROP TABLE, TRUNCATE, or DELETE FROM without WHERE

DROP TABLE events
git-history-rewritemedium

Rebase, amend or filter-branch (rewrites history)

git rebase origin/main
sudomedium

Command run with elevated privileges

sudo apt install …
outside-project-writemedium

File written or edited outside the project directory

~/.config/loader/config.toml
network-exfil-hintmedium

Data uploaded with curl/wget/Invoke-WebRequest to a non-local host

curl -d @data …
package-installlow

Package install (supply-chain awareness)

npm install stripe
chmod-permissivelow

World-writable or recursive permission change

chmod -R 777 public/uploads

# Fixtures

Anonymized sample logs for adapter tests. No real log content is committed here.

## How they were made

`claude-code/projects/…` was generated from real Claude Code logs by a script that keeps the JSON
structure and enum-like values (`type`, `subtype`, `model`, `version`, `stop_reason`, tool names,
token counts) and replaces everything else:

- free text (prompts, replies, tool output, file contents, titles) → `<key placeholder, N chars>`
- ids (`uuid`, `toolu_…`, `msg_…`, `req_…`, agent ids) → deterministic fake ids, consistently remapped so
  `parentUuid`, `tool_use_id`, `sourceToolAssistantUUID` and repeated `message.id` links still hold
- file paths → `C:\Users\USER\projects\demo-app\src\fileN.ext`
- shell commands → harmless placeholders (`npm test`, `git status`, …)
- timestamps → rebased to 2026-01-15
- MCP tool names other than `mcp__playwright__*` → `mcp__example__tool_N`
- `parentUuid` rewritten into a linear chain, because lines were sampled from several sessions

The output was then checked against the real logs: no real uuid or tool/message id appears, and no
string outside the placeholder patterns remains.

### `codex/`

Hand-written, modeled on real Codex Desktop rollouts (same keys and record order) and on Codex's
open-source rollout schema for CLI-only shapes. No real log content. Layout mirrors `~/.codex`.

- `sessions/2026/01/15/rollout-…-0198a1b2-c3d4-….jsonl`: Codex CLI. Injected `<environment_context>`,
  reasoning summary, `shell` function calls with `exec_command_end` (exit 0 and exit 1, JSON and plain-text
  outputs), `apply_patch` adding, updating and deleting files, `update_plan`, a web search, repeated
  `token_count` with unchanged totals, and an aborted turn.
- `sessions/2026/01/16/rollout-…-0198a1b2-d4e5-….jsonl`: Codex Desktop. `content_item_kinds`, encrypted
  reasoning, `exec` scripts whose `FileChange` / `CommandExecution` items replace them (one recursive
  delete for the risk rules), an `exec` script with no command, `token_usage_record` usage.
- `archived_sessions/rollout-…-0198a1b2-e5f6-….jsonl`: a Desktop import of another agent's session
  (`external-import-turn-1`). Expected: no session, no events, no warnings.
- `legacy/…`: pre-envelope rollout (bare meta line, `record_type: state`, `local_shell_call`).
- `malformed/…`: line 3 cut off, 4 blank, 5 array, 6 not JSON, 7 unknown line type, 8 unknown response
  item, 9–10 the same unknown `event_msg` twice (one warning), 11 orphan output with an invalid
  timestamp, 13 truncated last line without a newline.
